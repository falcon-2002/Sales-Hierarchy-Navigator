# 🌳 Interactive Sales Hierarchy Visualization

A dynamic, interactive tree diagram built with **D3.js** to visualize hierarchical product-category sales data. This tool allows users to explore deep data structures through intuitive animations and a modern dashboard interface.



## 🌟 Key Features
- **Collapsible Nodes:** Expand or collapse branches to focus on specific categories (e.g., Fruits vs. Toys).
- **Zoom & Pan:** Seamless navigation through large datasets using mouse-wheel zoom and click-drag panning.
- **Dynamic Search:** Instantly locate products using the real-time search bar which highlights matches in red.
- **Informative Tooltips:** Hover over any node to see detailed sales figures ($) pulled directly from the JSON source.
- **Responsive Design:** A sleek, sidebar-driven layout using "Inter" typography and categorical color coding.

## 🛠️ Technologies Used
- **D3.js (v7):** For data-driven document manipulation and SVG rendering.
- **JavaScript (ES6+):** For tree logic, search filtering, and event handling.
- **CSS3:** For modern "Glassmorphism" styling and smooth transitions.
- **HTML5:** For the structural layout and UI components.

## 📂 Project Structure
- `index.html`: The entry point and dashboard layout.
- `style.css`: Modern styling for the sidebar, chart, and nodes.
- `script.js`: The "brain" of the app containing the D3 logic and search functions.
- `hierarchy_data.json`: The data source containing the product-sales hierarchy.
